# Example entry: retrieval is a writing problem before it is a search problem

Search over a pile of saved articles returns the articles. It does not return
the reason any of them were saved, because that reason was never written down.

## Why it matters here

It is why the entry format has two sections and the validator fails an entry
missing the second one. The summary is recoverable from the source at any time.
The sentence explaining why it was kept is not.
