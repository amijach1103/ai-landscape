# Creating Icons for the Extension

You need three icon sizes: 16x16, 48x48, and 128x128 pixels.

## Quick Option: Use Emoji Icons

The simplest way is to create icons from emojis using a free online tool:

1. Go to: https://favicon.io/emoji-favicons/
2. Search for "newspaper" or "bookmark" emoji 📰 or 🔖
3. Download the generated icons
4. Rename them to:
   - `icon16.png` (16x16)
   - `icon48.png` (48x48)
   - `icon128.png` (128x128)
5. Save all three to the `chrome-extension` folder

## Alternative: Simple Colored Squares

If you just want to test the extension quickly:

1. Go to: https://dummyimage.com/
2. Create three images:
   - https://dummyimage.com/16x16/0066cc/ffffff&text=AI
   - https://dummyimage.com/48x48/0066cc/ffffff&text=AI
   - https://dummyimage.com/128x128/0066cc/ffffff&text=AI
3. Download each, rename as above
4. Save to `chrome-extension` folder

## Or Use Any Image Editor

Create simple icons in Photoshop, Figma, Canva, etc. with:
- Blue background (#0066cc)
- White text "AI" or newspaper icon
- Save as PNG at the three required sizes

**Once you have the icons, you're ready to install the extension!**
